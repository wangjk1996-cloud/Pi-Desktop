# Pi Desktop

pi coding agent 的 Windows 桌面客户端，提供多项目标签页、托盘驻留和自动更新。

> 界面内核来自上游项目 [pi-web](https://www.npmjs.com/package/@agegr/pi-web)（MIT），本仓库为其桌面化封装，并在此基础上实现了完整的自动更新体系。

## 下载与安装

从 [Releases](../../releases) 下载最新的 `PiDesktop-*-setup.exe`，双击安装即可。桌面和开始菜单会生成 **Pi Desktop** 快捷方式。

- 无需安装 Node.js、无需任何命令行操作
- 首次启动会自动下载内核组件（pi + pi-web，需联网一次，之后离线可用）
- 安装时若出现 SmartScreen 提示（应用未购买代码签名证书），点击"更多信息 → 仍要运行"即可

## 功能

- **独立桌面窗口**：无浏览器元素，任务栏独立图标
- **多项目标签页**：每个标签独立运行；新标签停留在首页，选择最近项目或目录后进入工作区。已打开的首页会同步更新项目列表、顺序和显示名称；无会话的新项目也会显示。可从最近项目移除条目，不会删除目录或会话。标签固定宽度，超出时可横向滚动或从列表切换
- **托盘驻留**：关闭窗口最小化到系统托盘，会话不中断；托盘菜单可重新打开或彻底退出
- **单实例**：重复启动只会聚焦已有窗口
- **端口自适应**：默认 30141；已有 pi-web 实例运行时直接复用
- **服务看门狗**：复用的外部服务一旦退出（例如关闭命令行的 pi-web），内置服务数秒内自动接管，页面自动恢复
- **外部链接**：一律交给系统默认浏览器打开
- **安全**：服务仅监听 127.0.0.1，不暴露到局域网

## 自动更新（三层，均无需手动操作）

| 层 | 对象 | 时机 |
| --- | --- | --- |
| 内核 | 应用内置的 pi-web / pi | 每次退出应用时检查，有新版则静默更新，下次启动生效 |
| 全局工具 | 本机 npm 全局安装的 pi / pi-web（命令行使用的） | 启动后后台更新；被占用或断网则下次重试 |
| 应用本体 | 窗口、托盘等外壳程序 | 启动时检查 GitHub Releases，下载完成后提示重启生效 |

所有更新均通过国内 npmmirror 镜像 / GitHub Releases 进行，失败自动静默重试，不影响使用。

## 与会话数据

- 会话、模型配置、凭据等与命令行的 `pi` / `pi-web` 完全共享（`~/.pi/agent`），可随时互换使用
- 内核与日志位于 `%APPDATA%\pi-desktop-app\`：
  - `kernel/` 应用内置内核
  - `pi-desktop-server.log` 服务日志
  - `update.log` 更新日志
  - `project-preferences.json` 首页项目顺序、显示名称、打开过的目录和移除记录（不更改项目目录或 pi-web 会话）

## 常见问题

- **双击没有反应**：先看系统托盘，应用可能已在运行（单实例锁会阻止重复启动）；或在任务管理器结束残留的 Pi Desktop 进程后重试
- **首次启动失败**：检查网络连接后重试，日志见 `%APPDATA%\pi-desktop-app\update.log`
- **卸载**：通过 Windows 设置正常卸载；用户数据保留在上述目录，可手动删除

## 从源码构建

```bash
npm install                 # 安装依赖
npm start                   # 开发模式运行（使用 vendor/npm 作为内置 npm）
npm run dist                # 打包 NSIS 安装包（输出 dist/）
```

目录结构：

```
main.js              Electron 主进程（内核管理 / 服务 / 窗口 / 托盘 / 看门狗 / 自更新）
build/               图标源文件（logo.svg 渲染生成）
scripts/             图标生成与打包辅助脚本
vendor/              内置 npm 运行时（tar.gz，不提交本仓库）
```
